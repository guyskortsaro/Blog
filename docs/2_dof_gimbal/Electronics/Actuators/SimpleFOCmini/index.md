# SimpleFOC mini v1.0

The SimpleFOC Mini v1.0 is a compact, open-source motor driver designed for precise control of brushless DC (BLDC) and gimbal motors using the Field Oriented Control (FOC) algorithm. Based on the DRV8313 three-phase gate driver, it supports up to 2.5A continuous current per phase and operates from a 7–24V input voltage. Its small footprint and compatibility with the SimpleFOC library make it ideal for embedded applications requiring accurate torque, velocity, or angle control. The board includes current sensing capabilities, flexible connector options, and is optimized for integration with magnetic encoders, making it well-suited for robotics, gimbals, and academic research projects.
